# Restricted data requirements

The portfolio-timing code is public, but its security-level input bundle is not.
The CRSP/WRDS license does not permit redistribution of the PERMNO-level return
matrices and holding-period factors stored in `timing_test_inputs.npz`.

## Required local upstream files

`prepare_inputs.py` expects the following files relative to `--project-root`:

```text
data/processed/nyse_big_caps_pit_daily.parquet
data/processed/nyse_small_caps_p20_p50_pit_daily.parquet
data/signals/V_uni.parquet
data/signals/V_small_uni.parquet
outputs/results/portfolio/audit/portfolio_monthly.parquet
```

These files must be generated by the point-in-time universe, signal, and
portfolio notebooks before preparing the timing-test bundle.

## Files generated locally

```text
data/timing_test_inputs.npz
data/timing_test_manifest.json
data/runtime_guard.json
data/runtime_guard_paths_<digest>.npz
```

All four files are ignored by Git. The first contains licensed CRSP-derived
security-level information. The runtime-guard files are host-specific and
should also be regenerated rather than redistributed.

## Reference identity

The SHA-256 of the restricted input used for the published experiment is
recorded in `reference/INPUT_SHA256`. This hash provides provenance without
disclosing the licensed data.
